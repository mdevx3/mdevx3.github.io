01 Problem

Extracting global debt patterns from 2,300+ raw indicators

International debt data from the World Bank spans hundreds of indicator types across 124 debtor nations — a highly dimensional dataset that is difficult to interpret without careful aggregation and cross-dimensional analysis. The raw data is structured but unwieldy: understanding which countries carry the highest debt burdens, which debt categories dominate, and how repayment obligations compare across nations requires complex SQL work, not just simple queries.

The challenge was to produce a clean, interpretable financial analysis using SQL alone — no Python, no visualisation libraries — demonstrating mastery of relational data modelling and query design.

02 Process

Multi-dimensional aggregation across countries and indicators

  • Designed layered SQL queries in PostgreSQL to aggregate 2,300+ debt indicators across 124 nations, using GROUP BY with multiple dimensions to surface total debt, principal repayments, and interest obligations by country and indicator category.
  • Used correlated subqueries to identify the single country with the highest total principal repayments, and to extract the most common debt indicator type across the dataset.
  • Handled NULL values carefully with COALESCE and conditional aggregation to prevent skewed totals where individual indicator records were missing.
  • Ranked countries by total debt using ORDER BY and LIMIT patterns, and cross-referenced against debt category breakdowns to understand whether debt was concentrated in long-term borrowing, short-term instruments, or concessional lending.
  • Structured the final query outputs into a financial reporting format — a series of named result sets suitable for presentation to a policy analysis audience.

#1
China by total repayments

China emerged as the highest-indebted nation by total principal repayments — a finding consistent with its large infrastructure borrowing portfolio under development finance programmes. The analysis also revealed that long-term external debt dominated the dataset, with a small number of high-income and upper-middle-income countries accounting for a disproportionate share of total obligations.

The project demonstrated that production-quality financial insight is achievable with SQL alone — no Python needed — and reinforced strong query design habits around NULL handling, aggregation correctness, and result interpretability.
